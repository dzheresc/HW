# k7_10g_os: license-free 10GBASE-R on both SFP+ cages

- GTX: free 7-series GT wizard (`ip/gtx10g`, generated by gen_ip.tcl), raw mode, 64-bit fabric
  width, 10.3125 Gb/s from the QPLL (GTXE2_COMMON in top.v, N=66 from the 156.25 MHz refclk).
- Gearbox: rtl/gearbox.v, 66b <-> 64b in fabric at 161.13 MHz. The PCS runs on a BUFGCE-gated
  copy of that clock (enabled 32 of 33 cycles), so it sees one block per edge at 156.25 MHz average.
- PCS: `eth_phy_10g` from verilog-ethernet (MIT, rtl/verilog-ethernet, commit 77320a9).
- Both cages transmit XGMII idle. No MAC or IP stack yet.

Build and run (PowerShell):

    C:\Xilinx\Vivado\2017.4\bin\vivado.bat -mode batch -source gen_ip.tcl    # only after IP changes
    C:\Xilinx\Vivado\2017.4\bin\vivado.bat -mode batch -source build.tcl     # ~45 min, synthesis is slow
    C:\Xilinx\Vivado\2017.4\bin\vivado.bat -mode batch -source program.tcl   # JTAG, volatile, prints status
    C:\Xilinx\Vivado\2017.4\bin\vivado.bat -mode batch -source program.tcl -tclargs 192.168.0.215:3121 noprog
    # with a VIO command: ... -tclargs 192.168.0.215:3121 noprog "set_ctl vio_rst 1; set_ctl vio_rst 0"

LEDs: 0 heartbeat, 1 QPLL lock, 2 TX+RX reset done, 3 SFP A block lock, 4 SFP B block lock,
5 heartbeat from the TX PCS clock.

VIO inputs: reset/lock flags, block lock / high BER / status per cage, PCS clock rates, and per
second counts of received idle words, local faults and remote faults. VIO outputs: `vio_rst`,
`vio_bitrev` (reverse bit order of GT words), `vio_rxpol` / `vio_txpol` (per-cage polarity).

Verified 2026-11-18: SFP A (DAC to the switch) and SFP B (loopback plug) both block-locked,
~156.25 M idle words/s, zero faults, zero errors; the switch shows SFP1 link at 10G.
